## HOW TO USE UPDATE_PROGRAMS

```
./update_programs.sh                   # devnet, pipeline completo
./update_programs.sh --net localnet    # localnet
./update_programs.sh --extend-only     # solo extiende, útil para diagnosticar
./update_programs.sh --deploy-only     # asume que ya extendiste
./update_programs.sh --skip-idl        # deploy sin tocar IDL accounts
```
